## Product Overview

Apeaksoft Phone Mirror projects the display of a mobile device onto a Windows computer, making it easier to view, operate, and capture phone content from the desktop. Since it works with both iOS and Android, it can support presentations, product demonstrations, application testing, tutorials, and regular screen-sharing tasks.

Connections are available through Wi-Fi or USB. Wireless pairing is convenient when you want to get started without a cable, while USB provides a direct link between the phone and PC. During a session, the computer can provide keyboard and mouse input, and the application can record the mirrored display, save snapshots, and synchronize rotation between the mobile device and desktop view.

## Getting Started

Follow these steps to begin a mirroring session:

1. Launch Apeaksoft Phone Mirror on Windows.
2. Select the desired connection type:
   - Choose Wi-Fi for a wireless session.
   - Choose USB for a direct wired link.
3. Pair the iOS or Android device.
4. Begin mirroring and view the phone through the application window.
5. Use the computer keyboard and mouse when desktop input is needed.
6. Record the session or take snapshots using the available capture controls.
7. Turn on rotation handling when the desktop view should follow the phone's orientation.

Wi-Fi is commonly convenient for presentations and testing when a quick wireless connection is preferred. USB may be preferable when you want a more consistent wired session.
